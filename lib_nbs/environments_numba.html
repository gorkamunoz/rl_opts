Encounter with targets for multi agents

source

check_collective_encounter_og

def check_collective_encounter_og(
    positions, target_positions, r, shared_depletion:bool=True
):

Given the positions of agents and targets, and a radius r, this function checks which agents are within radius r of each target.

If shared_depletion=True (default): at most one agent is assigned per target (random selection among those within radius), preserving competition — targets are globally depleted so only one reward per target per step.

If shared_depletion=False: each agent is independently assigned to its nearest target within radius, with no competition — multiple agents can encounter the same target in the same step.

Each agent is assigned to at most one target. Returns an array agent_to_target where agent_to_target[i] is the target index for agent i, or -1 if none.

source

check_collective_encounter

def check_collective_encounter(
    positions, target_positions, r, shared_depletion:bool=True
):

Optimized loop-based version of check_collective_encounter_og. No heap allocations: no reflected lists, no set, no (Na x Nt) distance matrix. Uses squared distances to avoid sqrt.

If shared_depletion=True: for each target, one random agent within radius is selected; an agent can only be assigned to one target (first-come wins). If shared_depletion=False: each agent is assigned to its nearest target within radius independently (deterministic).

Returns agent_to_target[i] = target index for agent i, or -1 if none.

    upd_pos_method:str='RND', # Method to update position. 'RND' for random angle turns, 'LR' for left/right turns.
    turn_angle:float=0.7853981633974483, # Angle for left/right turns if upd_pos_method is 'LR'.
):

Collective with fixed agents in target positions

We use this one to match the approximation to the theory, where agents can see targets. We place some agents in the target positions, they are always tagged as reward and they do not move.
