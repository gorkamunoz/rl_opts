Foragers_efficient

Efficient multi-agent version of the Forager class. Instead of updating h_matrix and g_matrix every step (as Foragers does with learn()), this class defers updates:

  • H-matrix: only updated on reward (or when max_no_H_update is reached). Between updates, deliberate() computes a virtual updated H column via precomputed prefactors.
  • G-matrix: only the visited (agent, action, percept) entry is touched each step (lazy decay). Full decay is flushed in _learn_post_reward().

Usage pattern (replaces learn(rewards) in the training loop):

agents.increment_counters()          # start of timestep
actions = agents.deliberate(obs)     # virtual H + lazy G
agents.act(actions)
...
agents._learn_post_reward(rewards)   # flush G, update H for rewarded agents

    initial_h_0:bool=False, # If to consider initial probability distribution for the H matrix or not.
    h_0, # value of initial h_matrix
    g_update:str='s', # Type of update for the G matrix. Can be 's' (sum) or 'r' (reset)
    max_no_H_update:int=10000, # Max number of steps without updating the H matrix
):

Efficient version of Foragers. Uses lazy H-matrix and G-matrix updates (only on reward or when max_no_H_update is reached), following the same strategy as the single-agent Forager class.

Key differences vs Foragers: - H-matrix is NOT updated every step. Instead, prefactors are used to compute the virtually-updated H column on the fly in deliberate(). - G-matrix updates are lazy: only the (agent, action, percept) entry touched during deliberate() is updated; the rest are deferred. - _learn_post_reward(rewards) replaces learn(rewards). It flushes the pending G-matrix decays and applies the accumulated H-matrix damping for each agent that received a reward (or hit max_no_H_update).

Per-agent damping version of Foragers_efficient.

gamma_damping and eta_glow_damping are arrays of shape (num_agents,), so each agent can use independent damping values.

is_learning is a boolean array of shape (num_agents,), controlling whether each agent updates h_matrix (True) or remains frozen (False).

Tests: Forager vs Foragers vs Foragers_efficient

Verifies that the efficient multi-agent class produces identical H and G matrices as: 1. Foragers (naive per-step updates) — G-matrix and H-matrix match after reward 2. Forager (efficient single-agent) — exact match for 1-agent case 3. @njit — compilation smoke test inside a Numba function

# === Test: G-matrix equivalence (Foragers vs Foragers_efficient) ===
print("=" * 60)
print("Test 1: G-matrix equivalence (Foragers vs Foragers_efficient)")
print("=" * 60)

num_agents_t = 3
num_actions_t = 2
ss_t = np.array([5])
gamma_t = 0.01
eta_t = 0.1

naive1 = Foragers(num_agents_t, num_actions_t, ss_t, gamma_t, eta_t)
eff1 = Foragers_efficient(num_agents_t, num_actions_t, ss_t, gamma_t, eta_t)

# Predefined (observation, action) sequences
obs_seq = [
    np.array([[1.0], [2.0], [3.0]]),
    np.array([[0.0], [1.0], [2.0]]),
    np.array([[2.0], [3.0], [4.0]]),
    np.array([[1.0], [0.0], [1.0]]),
    np.array([[3.0], [2.0], [0.0]]),
]
act_seq = [
    np.array([0, 1, 0]),
    np.array([1, 0, 1]),
    np.array([0, 0, 1]),
    np.array([1, 1, 0]),
    np.array([0, 1, 1]),
]

for t in range(5):
    obs = obs_seq[t]
    acts = act_seq[t]
    percepts = naive1.percept_preprocess(obs)

    # Naive: full G decay + update (what deliberate does internally)
    naive1.g_matrix = (1 - eta_t) * naive1.g_matrix
    for i in range(num_agents_t):
        naive1.g_matrix[i, acts[i], percepts[i]] += 1

    # Efficient: lazy G update
    for i in range(num_agents_t):
        eff1.N_upd_G[i] += 1
    for i in range(num_agents_t):
        eff1._G_upd_single_percept(i, percepts[i], acts[i])

# Flush efficient G to materialise lazy decays
for i in range(num_agents_t):
    eff1._G_upd_full(i)

diff_g = np.abs(naive1.g_matrix - eff1.g_matrix).max()
print(f"  Max G-matrix diff: {diff_g:.2e}")
assert np.allclose(naive1.g_matrix, eff1.g_matrix, atol=1e-12), "FAILED!"
print("  PASSED\n")

import time

# ── Training loop: Foragers (naive) ──────────────────────────────────────
@njit
def bench_naive(episodes, time_ep, agents):
    total_reward = np.zeros(agents.num_agents)
    for ep in range(episodes):
        agents.agent_states[:] = 0
        agents.reset_g()
        for t in range(time_ep):
            counters = agents.get_state().copy()
            obs = counters.reshape(-1, 1).astype(np.float64)
            actions = agents.deliberate(obs)
            agents.act(actions)
            # Simulated sparse reward: agent 0 gets reward every 50 steps
            rewards = np.zeros(agents.num_agents)
            if t % 50 == 49:
                rewards[0] = 1.0
            total_reward += rewards
            agents.learn(rewards)
    return total_reward

# ── Training loop: Foragers_efficient ────────────────────────────────────
@njit
def bench_efficient(episodes, time_ep, agents):
    total_reward = np.zeros(agents.num_agents)
    for ep in range(episodes):
        agents.agent_states[:] = 0
        agents.reset_g()
        for t in range(time_ep):
            agents.increment_counters()
            counters = agents.get_state().copy()
            obs = counters.reshape(-1, 1).astype(np.float64)
            actions = agents.deliberate(obs)
            agents.act(actions)
            rewards = np.zeros(agents.num_agents)
            if t % 50 == 49:
                rewards[0] = 1.0
            total_reward += rewards
            agents._learn_post_reward(rewards)
    return total_reward
